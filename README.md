# Video Lens 直播局部放大

> A Chrome/Edge extension that magnifies any region of a live stream (e.g. the streamer's camera) into a floating window, without re-fetching the video.

Chrome / Edge 扩展(MV3):在直播/视频页面框选任意区域(比如主播摄像头),生成独立悬浮窗口放大显示,原视频正常播放。支持**多窗口**与**多方案**(把当前窗口布局存成方案,一键切换),按直播间 URL 记忆,下次进入自动恢复。

## 安装(开发者模式)

1. Chrome 打开 `chrome://extensions`;Edge 打开 `edge://extensions`
2. 打开「开发者模式」
3. 点「加载已解压的扩展程序」,选择本目录(`video-lens/`)

## 使用

1. 打开斗鱼 / 虎牙 / B站直播 / YouTube / Twitch 的直播页,等视频开始播放
2. 点浏览器工具栏的扩展图标 → 「框选新区域」;可重复操作添加多个放大窗口
3. 回到页面,拖动鼠标框住主播摄像头(鼠标旁有 4 倍放大镜辅助对准边缘;松开后尝试自动吸附画面边缘),松开 → 自动生成放大悬浮窗(新窗口自动级联排开)
4. 悬浮窗平时只显示纯净画面;鼠标移到窗口上,顶部控制栏和右下角斜纹角标淡入——标题栏拖动移动、拖任意边缘/角落调整大小、滚轮或 ± 按钮调 1~5 倍、✕ 关闭;点击标题可重命名窗口(默认「窗口 1/2/…」)
5. **裁剪**:点悬浮窗控制栏的 ✂,在视频上直接拖动/拉角调整该窗口的选取区域,实时预览、所见即所得(不吸附);点空白处或 Esc 结束
6. **方案**:当前布局自动保存在「默认」方案;「另存当前布局」把现状快照成新方案,「新建」创建空白方案从零摆起,下拉框切换、可删除;名称留空自动命名。适合"只看摄像头"和"摄像头+小地图"等不同观赛布局
7. 全部配置按直播间记忆;「清除本直播间的全部记忆」可重置

## 支持站点

- `douyu.com`、`huya.com`、`live.bilibili.com`、`youtube.com`、`twitch.tv` (实际效果取决于站点播放器实现)

窗口布局与方案保存在浏览器的 `chrome.storage.local` 中。扩展本身不向外部服务器发送配置或视频画面。

## 实现要点

- **不克隆 video**:MSE 播放器(斗鱼 flv.js 一类)的 `blob:` 源一个 MediaSource 只能挂一个 `<video>`。改为直接对原 video 每帧 `drawImage(video, sx, sy, sw, sh, …)` 裁剪到悬浮窗的 canvas,零额外流量、无音画不同步。
- **帧调度**:优先 `requestVideoFrameCallback`(有新解码帧才画),不支持时退回 `requestAnimationFrame`。
- **智能吸附**:**仅框选时**松手吸附——抓取当前视频帧,在每条边 ±3% 范围内搜索平均梯度最强的竖直/水平线。摄像头窗口是"游戏画面→阴影→边框→内容"的多层结构,每层交界都是强线;吸附从最强峰出发向内容侧跳过边框/阴影层(10px 内、强度 ≥ 最强峰一半),落在**内容边界**上并 +1px 跳过过渡像素,避免把边框线裁进画面。只扫描边的中段 70% 规避圆角;峰值需同时超过绝对阈值和中位数 2.5 倍才吸附。裁剪调整不吸附,所见即所得。DRM/跨域读不到像素时静默回退为手选区域。
- **放大镜**:框选/裁剪时光标旁跟随一个 4 倍放大的圆形取景窗(直接从 video 元素绘制,无截图),十字准星始终对准光标实际指向;贴近画面边缘时越界部分显示为黑色,不产生偏移。
- **Shadow DOM 穿透**:斗鱼/虎牙/B站播放器把 `<video>` 包在 shadow root 里,用递归 `shadowRoot` 遍历查找,并按面积取最大可见视频。
- **object-fit 坐标映射**:框选与放大都基于"画面真实显示矩形"(处理 contain 黑边 / cover 裁切 / fill 拉伸),而不是 video 元素框,全屏、改窗口大小、切清晰度后坐标依然正确(存归一化坐标)。
- **全屏重挂**:`fullscreenchange` 时把悬浮窗重新 append 进全屏元素,否则不可见。
- **画面跟随**:窗口几何以"相对画面矩形的锚点"存储(位置/尺寸归一化到画面宽高)。剧场模式、网页全屏、全屏、窗口缩放、页面滚动导致画面大小/位置变化时,用锚点 × 当前画面矩形无状态重算,保持相对布局;锚点只在用户拖动/缩放窗口时更新,因此刷新后即使页面不在原来的显示模式,大小位置依然相对正确,反复切换也不会累积漂移。
- **SPA 换房**:监听 URL 变化(MutationObserver + 轮询 video),换直播间自动切换对应记忆配置。

## 已知限制(MVP)

- 视频在跨域 iframe 里的站点不适用(`all_frames: false`)
- DRM 加密视频(如 Netflix)无法读取画面
- 自动吸附依赖当前视频的像素边缘,复杂背景下可能选错边;可用 ✂ 手动修正
